# 🛡️ 실무형 CCE 취약점 조치 가이드 (2026)

이 저장소는 2026년 개정된 **주요정보통신기반시설 기술적 취약점 분석·평가 가이드**를 기반으로 작성된 UNIX/LINUX 서버 대상 실무 조치 가이드입니다.

## 📌 주요 특징
* **총 64개 항목 통합:** 기존 OS와 웹 서비스가 혼재되어 있던 기준에서 순수 OS 관점의 64개 항목만을 선별하여 정리했습니다.
* **실무 중심의 Action Item:** 단순히 가이드라인을 나열하는 것에 그치지 않고, 실제 인프라 환경에서 즉시 적용 가능한 명확한 점검 명령어(`As-Is`)와 조치 방법(`To-Be`)을 제공합니다.
* **OS별 맞춤 가이드:** RedHat(CentOS/Rocky) 계열과 Debian(Ubuntu) 계열의 명령어 및 경로 차이를 반영하여 실무 적용의 정확도를 높였습니다.
* **장애 예방 경고:** 무분별한 조치로 인한 서비스 장애를 방지하기 위해, 실무에서 반드시 확인해야 할 주의사항(Warning)을 포함했습니다.
